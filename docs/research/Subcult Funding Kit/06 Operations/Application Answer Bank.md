## 50-word description
Subcult Commons will make community applications on AT Protocol easier to operate and interoperate. We propose reusable tests and reference implementations for public-record lifecycle, organizational publication authority and private-data boundaries, informed by cultural-event and public-resource prototypes. Funding supports focused maintainer work, independent review, documentation and external reproduction.

## Problem
Public records become useful infrastructure only when independent applications can interpret them consistently and recover from failures. Small teams repeatedly implement publication permissions, ingestion, correction, deletion and migration behavior. These boundaries can leak private operational data or fail silently. Our proposed work makes the failure cases explicit and reproducible.

## Proposed result
A rights-cleared fixture and reference toolkit with a documented lifecycle contract; independently reproducible reader/rebuild exercises; negative authorization and sensitive-field cases; migration guidance; and a maintained public issue process. The first package deliberately excludes private-data protocol design, real political membership, production election systems and emergency services.
