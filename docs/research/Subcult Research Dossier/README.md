# Subcult Research Dossier

A portable research and proposal pack for a broader Subcult product combining scenes, artists, audiences and private event operations. Prepared 19 September 2026. This is a decision-support draft, not a launch announcement or investment forecast.

## Open in Obsidian

Copy this entire directory into any Obsidian vault, or use **Open folder as vault** to open it on its own. Start with [[Subcult Research Home]]. No community plugins, configuration files, accounts or scripts are required. Note names begin with “Subcult” to reduce collisions with existing vault notes.

Double brackets are Obsidian links. Click them to move between notes; the backlinks panel shows related notes. Every research note has a type, status and date in its frontmatter. The directory also works as ordinary Markdown, although a plain text reader will not turn double-bracket links into buttons.

For a conventional file browser, open [the research home](00%20Start%20Here/Subcult%20Research%20Home.md), [the executive proposal](01%20Proposal/Subcult%20Executive%20Proposal.md), or [the source register](07%20Research/Subcult%20Source%20Register.md).

## How to read the evidence

- **Observed source:** inspected repository code or documentation; not necessarily working software.
- **Vendor-stated:** a supplier's own description, not an independent product test.
- **Research finding:** sourced external context with its scope and date.
- **Proposal/hypothesis:** a recommended choice or experiment, not an existing commitment.
- **Unknown:** a question requiring a demo, agreement, interview or runtime test.

Dollar amounts are USD unless otherwise identified. Public prices are snapshots, not quotes. Geography, contract, tax, processor and messaging charges can change comparisons substantially.

## Boundaries

The original single-file proposal remains outside this standalone pack in the repository. Everything needed to understand this directory is included here; local repository paths are recorded as provenance text, not fragile machine-specific links. No secrets, customer lists, private event details or infrastructure credentials are included.

No customer interviews, paid competitor subscriptions, checkout purchases, production qualification, legal opinion or upstream acceptance were obtained. [[Subcult Research Methods and Refresh]] explains what desk research can and cannot establish. [[Subcult Decisions and Open Questions]] identifies the next decisions.

## Optional maintenance check

The pack includes a read-only [validation script](validate-dossier.mjs). With Node installed, run `node validate-dossier.mjs` from this directory after editing. It checks note targets, reachability, basic metadata structure, portable local links, placeholder markers and the listed scenario arithmetic. It does not fetch sources or verify factual claims. Obsidian does not require or run this script.
